ศูนย์รวมเครื่องมือตัดต่อ แต่งภาพ และทำเอฟเฟกต์ ทำงานในเบราว์เซอร์ทั้งหมด ไฟล์ไม่ถูกส่งขึ้นเซิร์ฟเวอร์

เวิร์กโฟลว์แนะนำ

LightCraft คัด/ล้างรูป RAW → PhotoCraft รีทัช ทำกราฟิก → EffectCraft โมชันกราฟิก ไตเติล → FilmCraft ตัดต่อ เกรดสี เสียง → export

ควรรู้

ไฟล์อยู่ในเบราว์เซอร์นี้เท่านั้นโปรเจกต์และสื่อที่ import จะเก็บใน storage ของเบราว์เซอร์ตามโดเมน ล้างข้อมูลเว็บเมื่อไรก็หาย ให้ Save / Export / Back Up ออกมาเก็บเองเสมอ
ส่งงานข้ามแอปExport จากแอปหนึ่ง (ไฟล์จะดาวน์โหลดลงเครื่อง) แล้วลากไฟล์นั้นไปวางในอีกแอปได้เลย
หน่วยความจำแต่ละแอปเป็น WebAssembly ขนาดใหญ่ เปิดพร้อมกันหลายตัวจะกินแรม ปิดแท็บที่ไม่ใช้ด้วยปุ่ม × ได้
ติดตั้งบน Androidเปิดเว็บนี้ใน Chrome แล้วกด “ติดตั้งแอป” ด้านบน (หรือเมนู ⋮ → เพิ่มลงในหน้าจอหลัก) กดค้างที่ไอคอนเพื่อเข้าแต่ละแอปได้ตรง ๆ
ใช้ออฟไลน์กด “ใช้ออฟไลน์” ใต้การ์ดเพื่อเก็บแอปไว้ในเครื่อง แอปที่เคยเปิดแล้วจะถูกเก็บเองบางส่วน มือถือแนะนำให้ต่อเมาส์/คีย์บอร์ด หรือใช้แท็บเล็ต
ภาพกระตุก/จอดำใช้ Chrome หรือ Edge (มี WebGPU) ได้ดีที่สุด ถ้ามีปัญหาให้กดปุ่ม ⚙ บนการ์ดเพื่อเปิดแบบ WebGL
