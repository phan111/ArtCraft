ควรรู้

ไฟล์อยู่ในเบราว์เซอร์นี้เท่านั้นโปรเจกต์และสื่อที่ import จะเก็บใน storage ของเบราว์เซอร์ตามโดเมน ล้างข้อมูลเว็บเมื่อไรก็หาย ให้ Save / Export / Back Up ออกมาเก็บเองเสมอ
ส่งงานข้ามแอปExport จากแอปหนึ่ง (ไฟล์จะดาวน์โหลดลงเครื่อง) แล้วลากไฟล์นั้นไปวางในอีกแอปได้เลย
หน่วยความจำแต่ละแอปเป็น WebAssembly ขนาดใหญ่ เปิดพร้อมกันหลายตัวจะกินแรม ปิดแท็บที่ไม่ใช้ด้วยปุ่ม × ได้
ภาพกระตุก/จอดำใช้ Chrome หรือ Edge (มี WebGPU) ได้ดีที่สุด ถ้ามีปัญหาให้กดปุ่ม ⚙ บนการ์ดเพื่อเปิดแบบ WebGL
